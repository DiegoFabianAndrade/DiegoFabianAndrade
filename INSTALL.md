# Final profile README package

## Files
- `README.md`: bilingual Spanish/English GitHub profile README.
- `assets/gta-loadout-hud.svg`: original animated SVG HUD with a radial technology selector inspired by open-world game loadout wheels, wanted stars, neon skyline, and radar.

## Install on GitHub
1. Open https://github.com/DiegoFabianAndrade/DiegoFabianAndrade
2. Open `README.md` and choose Edit (pencil).
3. Replace the current contents with this package's `README.md` and commit.
4. Create the `assets` folder if it does not exist, then upload `gta-loadout-hud.svg` to `assets/gta-loadout-hud.svg`.
5. Commit the asset and confirm the banner renders at the top of the profile.
