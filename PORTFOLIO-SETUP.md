# Pokémon Trainer Portfolio

## Publish with GitHub Pages

This is a static website. Keep `index.html`, `assets/site/`, and `.github/workflows/pages.yml` in the root of `DiegoFabianAndrade/DiegoFabianAndrade`.

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. Commit and push these files to `main`. The workflow will publish the site automatically.
4. Open the Pages URL shown in the workflow deployment. For this project repository it should be `https://diegofabianandrade.github.io/DiegoFabianAndrade/`.

GitHub profile stats are loaded from the public GitHub API. Animated shiny Generation V sprites are served by [PokeAPI Sprites](https://github.com/PokeAPI/sprites). The page includes a motion control and honors the operating system's reduced-motion preference.
